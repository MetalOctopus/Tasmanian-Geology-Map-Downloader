# Tasmania Radiometric WMS Layers Reference

WMS Service URL: https://www.mrt.tas.gov.au/erdas-iws/ogc/wms/?

## Quick Add to QGIS:
1. Layer → Add WMS/WMTS Layer
2. New connection → URL: https://www.mrt.tas.gov.au/erdas-iws/ogc/wms/?
3. Select layers below

## RGB Interpretation:
Red   = Potassium (K) - Dolerite, altered zones
Green = Thorium (Th)  - Granites, felsic rocks
Blue  = Uranium (U)   - Granites, mineralization

## Data Specs:
Resolution: 40m cell size
Projection: GDA94 / MGA Zone 55 (EPSG:28355)
Source: Airborne gamma-ray spectrometric surveys
Provider: Mineral Resources Tasmania
